# GOOGLE CLOUD STORAGE SETUP GUIDE — YOZORO

This guide explains how to configure Google Cloud Storage (GCS) for production video ingestion and secure streaming.

---

## 1. Bucket Strategy

YOZORO utilizes two private buckets:

1. **Staging Bucket:** `yozoro-staging`
   - Purpose: Receives raw, uncompressed video uploads via resumable upload sessions.
   - Access: Uniform Bucket-Level Access (private). No public access.
   - Lifecycle Rule: Automatically delete temporary objects older than 14 days.

2. **Media Bucket:** `yozoro-media`
   - Purpose: Stores transcoded HLS master playlists (`.m3u8`), variant playlists, and `.ts` media segments.
   - Access: Uniform Bucket-Level Access (private). No public access.
   - Access Control: All reads are authorized using short-lived Signed URLs generated by the backend.

---

## 2. Setting Up Buckets via gcloud CLI

```powershell
# 1. Set active project
gcloud config set project your-gcp-project-id

# 2. Create Staging Bucket
gcloud storage buckets create gs://yozoro-staging --location=us-central1 --uniform-bucket-level-access

# 3. Create Media Bucket
gcloud storage buckets create gs://yozoro-media --location=us-central1 --uniform-bucket-level-access

# 4. Set CORS policy on Staging Bucket for browser resumable uploads
# Create cors.json:
# [
#   {
#     "origin": ["http://localhost:3000", "https://amine-site-yozoro.vercel.app"],
#     "method": ["GET", "POST", "PUT", "OPTIONS"],
#     "responseHeader": ["Content-Type", "Content-Range", "x-goog-resumable"],
#     "maxAgeSeconds": 3600
#   }
# ]
gcloud storage buckets update gs://yozoro-staging --cors-file=cors.json
```

## 3. IAM & Service Account Configuration

1. Create a service account for the backend and worker:
   ```powershell
   gcloud iam service-accounts create yozoro-backend-sa --display-name="YOZORO Backend Service Account"
   ```

2. Grant Storage Object Admin role:
   ```powershell
   gcloud projects add-iam-policy-binding your-gcp-project-id `
     --member="serviceAccount:yozoro-backend-sa@your-gcp-project-id.iam.gserviceaccount.com" `
     --role="roles/storage.objectAdmin"
   ```

3. Export credentials or attach to Cloud Run:
   - For local development with GCP:
     ```powershell
     gcloud auth application-default login
     ```
   - In `.env`:
     ```env
     STORAGE_DRIVER=gcs
     GCS_PROJECT_ID=your-gcp-project-id
     GCS_STAGING_BUCKET=yozoro-staging
     GCS_MEDIA_BUCKET=yozoro-media
     ```
